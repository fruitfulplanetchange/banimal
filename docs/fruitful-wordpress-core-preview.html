What you'll actually see when it's installed

Real previews of the status page and the Elementor widget added in v1.1.0 — the plugin's first two pieces of visible functionality, on top of the API client, cache, and REST bridge that shipped in v1.0.0.

These render in WordPress's and Elementor's own chrome — this plugin holds no brand-specific styling of its own, by design. The one piece of front-end CSS it ships (assets/css/frontend.css) is deliberately minimal structure, not a finished look; a brand connector or theme is expected to style the widget's output.
